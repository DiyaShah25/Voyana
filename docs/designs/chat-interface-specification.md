## 1. Overview & UI Architecture

The Voyana AI Assistant panel provides travelers with an interactive, contextual conversation drawer for planning trips, generating custom multi-day itineraries, finding curated destination match recommendations, and querying budget allocations and packing requirements.

```
+-------------------------------------------------------------+
| [Voyana AI Sparkle] Voyana AI Copilot     (• Online)  [-] [X]|
+-------------------------------------------------------------+
|                                                             |
|  [AI Avatar] Hello! I'm Voyana AI. How can I assist your   |
|              travel planning today?                         |
|                                                             |
|                         [User] Can you suggest packing list |
|                                for Paris in Autumn?         |
|                                                             |
|  [AI Avatar] Here are my top packing recommendations:       |
|              - Trench coat / Windbreaker                    |
|              - Universal Power Adapter (Type C/E)           |
|              - Waterproof Walking Shoes                     |
|                                                             |
|  [🏷️ Weather Forecast] [🏷️ Packing Checklist]              |
|  +-------------------------------------------------------+  |
|  | ⚡ Action: Sync Weather Gear for Paris      [Apply]   |  |
|  +-------------------------------------------------------+  |
|                                                             |
+-------------------------------------------------------------+
| [ 💡 Recommend top destinations ] [ 📅 Plan 3-day trip ]   |
| [ Type your travel prompt...                        ] [Send]|
+-------------------------------------------------------------+
```

## 2. Component Specifications & Design Tokens

### 2.1 Header Navigation
- **Branding**: Voyana AI brand identifier with gradient sparkle avatar (`from-indigo-500 via-purple-500 to-pink-500`).
- **Real-time Status Indicator**: Green pulsating dot (`bg-emerald-500 animate-pulse`) indicating the AI reasoning engine is `Online`.
- **Modal Controls**: `Minimize` / `Expand` toggle button and `Close` button.
- **Explore Recommender Shortcut**: Quick compass button opening the Destination Recommendation drawer.

### 2.2 Message Flow & Alternating Bubbles
- **User Message**: Right-aligned pill with gradient accent (`from-indigo-600 to-indigo-700`), crisp white typography, and user avatar.
- **AI Assistant Message**: Left-aligned glassmorphic card with subtle white border, clear markdown formatting for lists, bold highlights, and headings.
- **AI Marking Badge**: "Generated by Voyana AI" badge with sparkle icon for transparent AI attribution.

### 2.3 Context Citation Chips
- Active pill chips beneath assistant messages (e.g. `Day 1`, `Day 2`, `Packing Checklist`, `Budget Planner`, `Weather Forecast`) indicating which segments of the trip were used to formulate the advice.

### 2.4 Action Shortcuts & Proposal Cards
- Integrated 1-click action buttons allowing users to open the **Budget Planner**, **Smart Packing Checklist**, or apply scheduled activities directly from the assistant's advice.

### 2.5 Composer & Quick Prompts Bar
- Multi-line textarea supporting `Enter` to submit and `Shift+Enter` for newline.
- Scrollable bar with pre-baked prompt pills (e.g., `"Recommend top travel destinations for me"`, `"Suggest a 3-day plan"`, `"What should we pack?"`).
