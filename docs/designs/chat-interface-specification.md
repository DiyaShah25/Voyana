# Chat Interface Design Specification (VPM-44)

## Overview
Design specification for the Voyana Assistant interactive panel corresponding to Mockup 5.4.

## UI Components & Specification

1. **Header**
   - Assistant branding ("Voyana AI")
   - Real-time online status indicator (green pulse badge)
   - Minimize / Collapse panel controls

2. **Message Flow & Alternating Bubbles**
   - **User Message**: Right-aligned, primary accent background, crisp white typography.
   - **AI Assistant Message**: Left-aligned, light surface card with subtle border, clear markdown formatting for lists and headings.
   - **AI Marking Badge**: "Generated by Voyana AI" badge with sparkle icon for transparent AI attribution.

3. **Context Citation Chips**
   - Active pill chips under AI responses (e.g. `[Day 1: Seminyak]`, `[Day 4: Mount Batur]`, `[Budget Breakdown]`) indicating which parts of the trip were used to form the response.

4. **Composer & Action Toolbar**
   - Multi-line autosizing text input with placeholder `Ask Voyana AI about packing, budget, or day plans...`
   - Quick prompt suggestion chips (e.g. "What to pack for Day 4?", "Check our budget status", "Suggest lunch near Ubud")
   - Send button with loading spinner state during LLM inference.
