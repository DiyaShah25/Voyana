# Documentation

This directory contains the documentation for the **Voyana** project.

## Current Documents

* **Project Proposal** – Provides an overview of the project, including the problem statement, objectives, features, technology stack, team roles, and development timeline.
* **Project Proposal V2** – Updated version of the project proposal with the latest project details and refinements.
* **Timeline Sheet & Board** – Contains the project timeline, task planning, milestones, and development tracking in Jira.
* **Technical Findings & BaaS Evaluation (`docs/findings.md`)** – Technical research and design decisions for Booking Services & Payment Integration (VPM-22).
* **Database Design Review (`docs/db-review.md`)** – Schema design review, ER diagrams, 3NF normalization, RLS policies, and trigger automation (VPM-28).
* **Manual Testing Guide (`docs/manual_testing_guide.md`)** – Test cases and verification steps for Booking Services & Realtime Alert Pipeline (VPM-93).

Additional documents such as the Software Requirements Specification (SRS), API Documentation, and Deployment Guide will be added as the project progresses.
